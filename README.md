# EE Toolkit

Free tools for IB Extended Essay students and supervisors: https://ee-toolkit.github.io

- `index.html` — EE Builder: subject, research direction and question, variables and method, essay blueprint, checkpoint plan.
- `subject-chooser.html` — "Which subject for your EE?"
- `apa7.html` — APA 7 reference and in-text citation builder.
- `site.js` — shared footer: links between the pages, download/load of the student's work, notes about the content.

Plain HTML pages, no server and no build step. Students' work is kept only in their own browser (localStorage); nothing is sent anywhere.

The content was compiled with AI (Claude) and should be reviewed by subject teachers.
Not affiliated with or endorsed by the International Baccalaureate.
